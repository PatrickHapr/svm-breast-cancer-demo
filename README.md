# 🩺 SVM - Wisconsin Breast Cancer (demo Streamlit)

Demo web interativa do modelo SVM publicado em
[https://huggingface.co/Hapyr/svm-breast-cancer-wisconsin](https://huggingface.co/Hapyr/svm-breast-cancer-wisconsin).

Entrada: 30 features do dataset Wisconsin Breast Cancer → saída **Benigno/Maligno** com probabilidade.

## Rodar localmente

```
pip install -r requirements.txt
streamlit run app.py
```

Abrir http://localhost:8501
